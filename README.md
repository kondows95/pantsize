# Pantsize

写真内の既知の長さを基準にして、ほかの部分の寸法を比例換算するiPhone用の画像定規アプリです。SwiftUIで実装しています。

## 開発

`Pantsize.xcodeproj` をXcodeで開いてください。実機で動かす場合は、Signing & Capabilitiesで自身の開発チームを選択します。

対応OS：iOS 17.0以降。

## データの扱い

利用者が選択した画像と計測データは端末内に保存します。広告・アクセス解析SDKや、開発者サーバーへの送信処理はありません。端末の設定によりOSのバックアップに含まれる場合があります。
