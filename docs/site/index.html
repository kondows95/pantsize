Pantsize サポート

写真の比率から、服のサイズを確かめる。

Pantsizeは、長さが分かる部分を基準にして、同じ写真内のほかの部分の寸法を推定する画像定規アプリです。

基本の使い方

  1. 商品画像を写真アプリに保存します。
  2. Pantsizeの右上の「＋」から画像を選びます。
  3. 長さが分かる部分の始点と終点を指定し、計測線を引きます。
  4. その線を基準計測に選び、分かっている長さをcmで入力します。平置きのウエスト幅を測る場合は、周囲の長さではなく、その幅に対応する値を入力します。
  5. 計測を追加して、股下など知りたい部分に線を引きます。「換算値」で推定した寸法を確認できます。

画像はピンチで拡大でき、線の端点をドラッグして調整できます。保存した計測は一覧から開き直せます。

よくある質問

換算値が表示されません

基準にする線の始点と終点を指定し、基準計測を選んで、0より大きい実測値を入力してください。知りたい部分の線も始点と終点の両方が必要です。

実際の寸法と違うのはなぜですか？

換算は画像内の長さの比率によります。撮影角度、レンズの歪み、生地のしわ、基準値や端点の位置によって誤差が生じます。換算値は購入判断の参考であり、正確な寸法や商品の適合、返品・交換を保証するものではありません。

写真を読み込めません

写真アプリで画像が開けることを確認し、もう一度選択してください。iCloud上の画像は、端末へダウンロードするために通信が必要な場合があります。

データはどこに保存されますか？

選んだ画像と計測データは端末内に保存されます。開発者のサーバーへの送信や、アプリ独自の端末間同期はありません。端末の設定によってはOSのバックアップ対象になります。

保存したデータを削除するには？

プロジェクト一覧のごみ箱ボタンを押し、「削除」を選んでください。元の写真は写真アプリから削除されません。削除したプロジェクトをアプリ内で元に戻す機能はありません。
